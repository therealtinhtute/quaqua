# Summary: Step-Level Blocked Gate in PipelineWorkflow (W2 Task 1)

## Commits
- `92a7bd5` feat(pipeline): step-level blocked gate and restart/exhausted resume

## Changes
1. **`pipeline/state.rs`**:
   - Added `PipelinePhase::Blocked`.
   - Added `BlockedKind` enum with variants `Restart` and `RoundsExhausted`.
   - Added `ResumeDirective { max_rounds: u32 }` with serde derive.
   - Added `parse_blocked_gate(reason: &str) -> Option<(i32, String)>` parsing both raw `"blocked {code}: ..."` and runner-wrapped `"pause_for_approval: blocked {code}: ..."`.
   - Extended `PipelineWorkflowState` with `blocked_from: Option<PipelinePhase>`, `blocked_kind: Option<BlockedKind>`, `blocked_code: i32`, and `blocked_reason: Option<String>` (all with `#[serde(default)]`).
2. **`pipeline/mod.rs`**:
   - Added `block(state, from, kind, code, reason) -> StepDecision<PipelineOutput>` helper transitioning state to `PipelinePhase::Blocked`, setting blocked metadata, and returning `StepDecision::PauseForApproval { reason: format!("blocked {code}: {reason}") }`.
   - Converted all 8 recoverable fail-sites in `PipelineWorkflow::step` from terminal `Fail` to `block(...)`:
     - Child worker invalid output contract (`code 6`, `Restart`, `from=state.phase`).
     - `ChildCompleted` with `exit != 0` (`code exit`, `Restart`, `from=state.phase`).
     - Plan report unfinished (`code 5`, `Restart`, `from=Plan`).
     - Build report unfinished (`code 5`, `Restart`, `from=Build`).
     - Review verdict unparseable (`code 6`, `Restart`, `from=Review`, same round).
     - Fix report unfinished (`code 5`, `Restart`, `from=Fix`).
     - Report file read returned unexpected result (`code 3`, `Restart`, `from=state.phase`).
     - `ChildFailed` event (`code`, `Restart`, `from=state.phase`).
     - Review rounds exhausted (`code 5`, `RoundsExhausted`, `from=Review`).
   - Extended `ApprovalResolved` handling:
     - `PlanReadyGate`: stays unchanged (`approved=false` -> `Fail { code: 1, reason }`).
     - `Blocked` + `approved=false` -> terminal `Fail { code: 1, reason: "blocked gate aborted" }`.
     - `Blocked` + `RoundsExhausted` + `approved=true`: parses `ResumeDirective` from `reason`, sets `max_rounds = max(old, directive.max_rounds)`; if `round < max_rounds`, transitions to `Fix` and starts child, otherwise pauses again in `Blocked`.
     - `Blocked` + `Restart` + `approved=true`: resets `phase = blocked_from`, rebuilds child for that phase (same id and round), and emits `StartChild`.
     - `None` event under `Blocked`: continues to return `PauseForApproval`.
3. **`engine/runner.rs`**:
   - Added Test 11 (`test_two_sequential_pause_resolved_cycles_kill_between_dispatches_nothing`) verifying that two sequential `PauseForApproval` / `ApprovalResolved` cycles interrupted by a kill between them replay cleanly without re-dispatching any duplicate events, guarding the per-count dispatch logic.

## Lessons
