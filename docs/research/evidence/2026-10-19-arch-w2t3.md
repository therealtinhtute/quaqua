## Unknowns Resolution
The facts that the existing gate code (`crates/quaqua/src/pipeline/mod.rs:1511-1514`) reads which the initial design's `BuildFacts` lacked are:
1. `builder` (`state.builder`): worker name running the build step.
2. `task` (`ctx.task`): pipeline task slug.
3. `repo` (`state.repo`): repository name.

These facts are required to format the exact Blocked message:
`"builder produced no commits on quaqua/{builder}-{task} (HEAD == base {base7}) and did not declare 'Outcome: no changes' — commit the work (or fix the report), then 'quaqua pipeline --resume {task} {repo}'"`.
They have been added as fields `builder: String`, `task: String`, `repo: String` on `BuildFacts`.
